## Как открыть

Откройте `presentation/index.html` в браузере (локально или через любой статический сервер).

```bash
cd presentation && python3 -m http.server 8080
```

Затем перейдите на http://localhost:8080

## Управление

- ← / → или пробел — слайды
- `N` — заметки докладчика
- `F` — полный экран
- На титуле можно вписать ФИО, группу и дисциплину
